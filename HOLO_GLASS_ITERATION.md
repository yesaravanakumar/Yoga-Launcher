# Yoga Launcher — Holo Glass iteration

- Adds a Holo Glass 3D-card app launcher overlay to the existing HTML interface.
- Opens by tapping the Golden Lotus logo, clock logo, or mandala.
- Provides exactly three visible lifestyle modes: Gaming, Business, Entertainment.
- Keeps the Golden Lotus gold/black visual treatment in every mode.
- Persists the last selected mode locally.
- Tries installed-app matching first, then falls back to relevant web destinations.
- Respects reduced-motion preferences.

The existing Android project is preserved. Test in Android WebView and run the Gradle build before publishing.
