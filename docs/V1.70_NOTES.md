# v1.70: settings spotlight tray

Settings > any slider: touching a slider opens a bottom tray with the setting name, a large live value, a reset (back to the value at open), - and + step buttons, a value bubble over the thumb, and "Hold to compare" (shows the original while held). The tray drives the real slider, so all existing live previews and handlers apply. Done or closing Settings dismisses it.

Not yet: element-specific mini previews per slider (phase 2).
