# v1.44 (drawer motion)

All in `app/src/main/assets/index.html`. New setting: **App drawer > Motion effects** (Full / Soft / Off), key `dfx`, default Full.
Soft = fades only (Performance mode and reduced-motion behave like Soft/Off). Off = none of the items below.

- Open: the drawer eases in (slight zoom), the search bar, chips, info panel, A-Z button and arc slide in one after another, and the arc scale grows out from the focus lens
- Fan out is now a wave: apps near the focus open first, outer apps follow, with a small springy overshoot. Closing collapses the outer apps first
- Switching category re-fans the apps (search typing does not, so it stays calm)
- An app that lands in the thumb zone bounces; a ripple leaves the focus lens when the wheel settles
- Icons squish when pressed; the tapped app bursts outward as the drawer closes
- The big background letter slides in when the letter changes; the selected chip and the pin star pop
