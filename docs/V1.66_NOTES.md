# v1.66: one Edit home panel, and a drag handle to resize widgets

## 1. One edit mode
- **Hold empty space on the home screen** (wallpaper area, no clock/date/search/dock under your finger) now opens **Edit home**, a single panel at the bottom with four tabs:
  - **Wallpaper**: swatches, Choose image, Remove, Dim, Blur.
  - **Widgets**: switches for the cards (clock/date, weather, battery, calendar, tasks, focus, recents), Add widget, Stacks & sizes, Move clock & date.
  - **Grid**: home screen columns and rows, home page grid columns and rows, icon size, app names, apps on home, lock home layout.
  - **Settings**: All settings, plus quick jumps to Clock, Date, Search, Dock, Weather.
- Holding the clock, date, search bar, weather line, page dots or dock still opens just that part of Settings (unchanged).
- If you assigned your own action to "Long-press on empty home" in Gestures, that action still wins. "Edit home" is now in that list too.
- Done button or Esc closes it. Real Android widgets are hidden while the panel is open.

## 2. Widget stacks and resizing in the page
- **Resize handle**: each widget on the Widgets page has a grip bar under it. Drag it up or down to set the height (60 to 420 px, shown live). Arrow keys on the grip also work. S / M / L are still there as presets and clear the custom height.
- **Stacks** (already in the page, now easier to see): Stack puts another widget in the same slot, and the ‹ › buttons flip through it. New: an "n/total" counter next to the dots.
- In the browser/preview (no Android app) Add widget now adds a **placeholder** so you can try stacking and resizing. On the phone it still opens the real Android widget picker.
- The page tells the Kotlin side the new size through the existing placeWidget call, so **no Kotlin change**.

## Not done / limits
- Resize is height only. Width is the full page width.
- Stacks still live on the Widgets page, not as free-floating widgets on the home screen itself.
- Checked in headless jsdom (tools/smoke/edit-test.js, 20 checks) and no page errors. Not yet seen on a real phone: the panel look, and the real widget following the drag.
- tools/smoke/hold-test.js has one old failing check (expects "Clock" for the date element, gets "Date bar"). It fails on v1.65 too.
