# v1.71: settings spotlight (replaces Preview)

- Removed the **Preview** button from Settings.
- **Spotlight**: changing any setting (slider, switch, dropdown, chips, colour) fades the sheet and dims the home screen except the element that setting controls (ringed): clock / glass capsule, mandala, dock, search bar, at-a-glance card, date block, launcher logo. Settings that change a whole surface (App drawer, Search, Widgets, Icons & grid, Arc themes) still open that surface as before; global ones (wallpaper, theme, effects) simply reveal the home screen.
- The v1.70 slider tray stays open with the spotlight held while you fine-tune; the screen no longer gets a dark overlay behind it.
- Switch: Settings > Comfort/Hub "Spotlight the changed element" (same stored setting as the old Auto-preview, default on).
Checked in Chromium (SwiftShader). Not tried on a device.
