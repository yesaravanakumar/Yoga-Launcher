# v1.76: date / day / weather widget
Settings > Date bar (home) now has:
- **Date & weather style** gallery with live previews: Classic, Big day, Glass card, Chip, Minimal, Accent bar.
- **Date & weather size** slider (50-250%, same value as the Layout pinch/drag resize).
- **Weather text size** slider (60-200%).
- Reset date & weather. Changing any of these spotlights the date block on the home screen.
Note: bigger styles (Glass card, Big day) can overlap the glance card under them; use Layout > move, or a smaller size.
