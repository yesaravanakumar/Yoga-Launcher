# v1.68: pill colours + Play release prep

## Glass capsule colour (the default home clock)
The default home clock is the 3D glass capsule, which hides the classic pill, so the colour option lives here too.
Edit home > Clock > **Capsule colour**: Silver (original, default), Follow theme (minutes and hours take the first accent, seconds the second), Night (dark panel, digits in the theme colours), Gold, Rose, Mint, Sky, Sunset, or Custom (your own panel and digit colours).
Reset this section returns to Silver. The shader change adds two colour arrays (`u_paint`, `u_ink`) and compiles clean in a GLSL validator; tests: `tools/smoke/capsulecolor-test.js` (14 checks, fake WebGL).
Not seen on a real GPU yet.

## Pill clock colour (Dial clock style only)
Edit home > Clock > **Pill colour** (also in Settings > Clock). Choices:
- **Follow theme (default)**: minutes use the theme's first accent, seconds the second. Changes with the theme, as before.
- **Theme, swapped** and **Theme accent only**: still follow the theme.
- **Soft white, Gold, Sunset, Rose, Mint, Sky, Lime**: fixed pairs that stay when the theme changes.
- **Custom...**: pick your own minutes and seconds colours.
The colour also drives the pill's tint and the Outline / Neon edge, and applies to the lock-screen pill. "Reset this section" returns to Follow theme.
Not changed: the 3D glass capsule clock (v1.61) draws its own colours.
Tests: `tools/smoke/pillcolor-test.js` (15 checks, headless).
