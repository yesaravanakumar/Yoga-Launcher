# v1.68: pill colours + Play release prep

## Pill clock colour
Edit home > Clock > **Pill colour** (also in Settings > Clock). Choices:
- **Follow theme (default)**: minutes use the theme's first accent, seconds the second. Changes with the theme, as before.
- **Theme, swapped** and **Theme accent only**: still follow the theme.
- **Soft white, Gold, Sunset, Rose, Mint, Sky, Lime**: fixed pairs that stay when the theme changes.
- **Custom...**: pick your own minutes and seconds colours.
The colour also drives the pill's tint and the Outline / Neon edge, and applies to the lock-screen pill. "Reset this section" returns to Follow theme.
Not changed: the 3D glass capsule clock (v1.61) draws its own colours.
Tests: `tools/smoke/pillcolor-test.js` (14 checks, headless).
