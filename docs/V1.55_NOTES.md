# v1.55 notes: NEW badges and notification dots on the Arc Wave drawer

- **Notification dots and counts:** every app on the arc, and the big selected icon, shows a small bubble at its top-right when the app has notifications. It shows the number (99+ above 99) or a plain dot when Settings > Alerts > Counts is off.
- **NEW badges:** apps installed since you last opened them show a NEW pill on the bottom edge of the icon. It clears when you open the app (same rule as the Grid drawer).
- **Uses your existing settings:** Notification badges (`nbd`), Counts (`nbn`), Package monitoring / NEW badges (`pmon`) and Hide smart card and NEW badges (`shin`) all apply to the arc now.
- **New arc options** (Arc settings > Look): "Notification dots and counts" and "NEW badges". Both on by default. Reset all restores them.
- **Live:** counts refresh when the drawer opens, when the app is handed new counts (`setBadges` / `onBadges`), and every 8 seconds while the drawer is open and visible. The timer stops when the drawer closes.
- **Minimal mode and hidden names:** the bubbles and NEW pills stay visible, since they are the only status cue left.
- **Screen readers:** each app's label adds ", 3 notifications" and/or ", new app", and the selected app's name announcement includes the same text.
- **Motion:** the bubble pulses gently; it stays still with reduced motion, Arc "Animations" off, or Performance mode.
- **Contacts view:** no badges (contacts have no package).
- Needs Notification access for real counts (Settings > Alerts > Notification access). No Kotlin change.
- Changed: `app/src/web/index.src.html` and generated `assets/index.html`; `APP_VER` and `versionName` now 1.55.
- Checked in headless Chromium (390x844): counts, 99+ cap, dot-only mode, NEW on/off, both arc toggles, `shin` hides everything, launching clears NEW, live `setBadges` update, selected icon badge and screen-reader text, minimal mode, Grid layout still works. No page errors. The jsdom smoke tests were not run (dependencies are not installed here).
