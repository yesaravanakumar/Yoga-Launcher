# Parked native code (not compiled)

`YogaNativeV19.kt` adds now-playing, next calendar event and real Android widgets.
It is kept here, outside `app/src`, so it cannot break the GitHub build.
It has not been compiled yet. To switch it on, follow `V19_SETUP.md`, move the file to
`app/src/main/java/com/yoga/launcher/`, and push. Check the Actions tab afterwards.
