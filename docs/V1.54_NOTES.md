# v1.54 notes: Grid app drawer in Settings

- **Settings > App drawer > Drawer layout:** choose **Arc Wave** (default, unchanged) or **Grid**.
- **Grid** is the classic drawer: icon grid with names, A-Z rail, category chips (All, Pinned, Contacts, ...), search, Reorder and Select. When Grid is chosen, a **Grid style** row appears: Grid, List, Smart (favourites, suggested, recent first), Pages (swipe left/right). The drawer-header style button offers the same four.
- The Arc-only rows (Minimalistic drawer, All arc options) are hidden while Grid is chosen; the dial-panel gear and Arc settings sheet only belong to Arc Wave.
- The choice is saved (`yoga-dlay`) and applied at start; switching takes effect on the next drawer open (or immediately if the drawer is open).
- How: the classic drawer functions are kept (`window.__YD0`) before Arc Wave replaces them, and swapped back onto `YD` when Grid is chosen. `window.drawerLayout.get()/set('arc'|'grid')` is available for gestures or code.
- The old Crescent wheel is no longer offered in the style pop-up (Arc Wave replaces it).
- Changed: `app/src/web/index.src.html` and generated `assets/index.html`. No Kotlin change.
- Checked in headless Chromium (390x844): switch both ways, all four grid styles render, tapping an app launches and closes, choice survives reload, no page errors. Smoke tests: same results as v1.53.
