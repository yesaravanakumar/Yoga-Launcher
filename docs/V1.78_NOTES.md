# v1.78: professional pass on the Arc Wave app drawer

Fixed
- Black boxes behind some apps: the fly-in animation class "in" clashed with the global text-input style. Renamed to "awin" (and removed after the animation).
- Selected app name no longer runs over the A-Z letters: it shrinks (down to 13px) to the free space, then ends with an ellipsis.
- Depth blur is off by default (it smeared the names). Saved settings are migrated once (aw-cfg, cfgv 78). Distance is shown with a gentle size falloff instead.
- List icons and the selected icon share one rounded-square shape (the shape picker still overrides).
- Top tools (Sort / Reorder / Select) are one capsule; the Select bar and Reorder hint no longer clip.
- Smoother scrolling: spinning rings, glow lines and scan line pause while the list moves (class "busy"); app labels no longer use live backdrop blur.

Code: edits inside `<script id="v60-arcwave">` plus a last style block `<style id="v178-drawer-pro">` (double-id selectors "#aw#aw" so it wins over older layers).
Known limits: very long names still end with "..." after shrinking; the first-open tip toast overlaps the list for a few seconds.
