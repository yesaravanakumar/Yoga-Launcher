# v1.63: Home screen grid size, choose-the-cell, lock layout

All three are in Settings next to **Apps on home screen** (Widgets section). They apply to the clock home screen icons (the pages with the dots), not the separate Home page grid.

## 1. Grid size and name size
- **Home screen columns**: 3, 4, 5 or 6 (default 4). The 320 px width is shared by the columns, so icons shrink to fit if needed.
- **Home screen rows**: Auto (as many as fit, default) or a fixed 4 to 7. A fixed number stretches or squeezes the cell height to fit.
- **Home app name size**: 70 to 150 %. **Show app names on home** hides the names completely.
- If you shrink the grid, icons that no longer fit move to the nearest free cell (same page first, then other pages, then a new page). Nothing is deleted. If there is no room at all, a message says how many did not fit.
- The old "Grid columns / Grid rows" controls were renamed **Home page grid columns / rows** because they belong to the separate Home page.

## 2. Choose the cell
- **When I add an app**: *I choose the cell* (default) or *First free cell*.
- With *I choose the cell*, **Add to home screen** (app menu, arc menu) closes the drawer and shows the free cells of the current page. Tap a cell to place the app. Use the page dots to pick another page, `+` for a new page, **First free cell** to let the launcher choose, **Cancel**, Back or Esc to give up (the app is then not added).
- Adding several apps at once (arc multi-select) still uses the first free cells, because picking a cell for each would be slow.
- Dragging an app from the drawer onto a cell still works as before.

## 3. Lock home layout
- **Lock home layout** (also a Quick settings tile "Lock home"): icons cannot be dragged, moved, dropped on the dock or page dots, or removed; pages cannot be deleted; **Remove all home screen apps** is disabled.
- Long-pressing a locked icon opens its app menu, where the remove entry reads "Home layout is locked".
- Adding apps still works while locked.
