# v1.53 notes: Arc settings in the dial panel

- **Settings gear moved into the dial panel.** It is now the last button in the same column as Search, Contacts, Edit, Star, Home, Play Store, Info and Uninstall (mirrors Search at the top). It lights up while the sheet is open. It stays visible in Minimalistic mode so you can always turn things back on.
- **Smaller panel icons.** Buttons 48 -> 40 px, glyphs 24 -> 20 px, Home hub 46 px. The column is re-spaced evenly around the hub so the extra gear fits. The "Button size" slider still scales them.
- **Settings sheet is easier to use, and changes are live:**
  - New **Quick** tab (first): line position, app spacing, icon size, dial position, dial size, button size, names, A-Z, accent colour.
  - **Fade while dragging:** touch a slider and the rest of the sheet fades out; only that one row stays, so the whole arc is visible while you adjust it.
  - **Per-setting reset:** a small undo arrow appears next to any slider that differs from default.
  - **Reset all** now asks for a second tap before wiping everything.
  - Sheet is shorter (44% of the screen, max 360 px), tabs scroll sideways, slider thumbs are larger, values save while you drag.
- Back button and Done still close the sheet; Settings -> App drawer -> "All arc options" still opens it.
- Fixed while testing: a class-change watcher on the sheet could loop and freeze the page on close (never shipped).
- Changed: `app/src/web/index.src.html` (and the generated `app/src/main/assets/index.html`). No Kotlin change.
- Checked in headless Chromium at 390x844: gear opens/closes the sheet, slider drag fades and saves to `aw-cfg`, row reset, Back, Minimal mode. Existing smoke tests unchanged (check2 has 2 older failures: unread badge, next-meeting card).
