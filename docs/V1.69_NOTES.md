# v1.69: capsule label colour, more capsule colours, minutes/seconds motions

Edit home > Clock (glass capsule on):
- **Label colour (MON)**: Match digits (default), Theme colour 1/2, White, Black, Gold, Rose, Mint, Sky, Sunset, Ruby, Lime, Custom.
- **Capsule colour**: new presets Ruby, Ocean, Lime, Violet, Copper, Graphite and Tri-colour (hours / minutes / seconds each a different colour).
- **Minutes change motion** and **Seconds change motion** (separate): Roll (original, default), Smooth glide, Bounce, Spring wobble, Fade, Instant.
- **Motion speed** 50-250% (applies to minutes and seconds).
"Reset this section" restores all of these. Tests: tools/smoke/capsulecolor-test.js updated (16 colours + new checks); checked visually in Chromium (SwiftShader WebGL).

## v1.69 addition: neighbour-digit blur
Edit home > Clock > **Blur on previous / next digits** (0-100%, default 70%): the digits just passed and about to come, on hours, minutes and seconds, are blurred and dimmed; the current digit stays sharp. 0% = original look.
