# v1.51: Android platform behaviour

New page: the v1.50 "dial" page (Arc Wave drawer, matte surfaces, dial designs, touch controls) plus a platform layer (`v75-platform-js` in `index.src.html`). Native side updated to match.

## Page
- **Reduce motion** (Settings > Display & accessibility): Follow system / On / Off. Live. Follows the system "Remove animations" switch through `Android.getReduceMotion()` and `window.setReduceMotion(b)`.
- **Battery saving**: on Battery Saver or 15% and below while unplugged, decorative loops stop and Smooth mode turns on. Switch in the same place. Native feeds `window.setPowerSave(b)`.
- **Back / Home**: Back also leaves icon-edit mode and theme preview. Home closes every panel, leaves edit modes, drops focus and scrolls Settings to the top.
- **Default home app**: status and "Set as default" in Settings; manual-steps dialog if the system picker cannot open.
- **Sizing**: usable area is the window minus system insets; scale is capped at 2.4 on tablets; `html.wide` marks landscape and wide windows (the home column stays centred); refit after rotation or fold.
- **Accessibility**: Home actions (Open all apps, Search, Widgets, Settings) and the time as text for TalkBack and keyboards; overlays are modal dialogs with focus moved in and restored; unnamed controls get names; high-contrast and forced-colors styles.
- **System bar icons** follow the Light / Dark theme through `Android.setBarsLight(b)`.
- Removed the non-standard `screen-orientation` and `x5-orientation` meta tags.

## Native (Kotlin and manifest)
- `YogaBridge.kt`: new `isDefaultLauncher`, `requestDefaultLauncher`, `isPowerSave`, `getReduceMotion`, `setGestureExclusion` (was called by the page but missing), `setBarsLight`. `haptic` now works on Android 8-9 and stays quiet when the phone's touch feedback is off. Default-home request falls back to Home settings, then Default apps, then Settings, then the page's help dialog.
- `MainActivity.kt`: edge-to-edge on Android 11+ (transparent bars, cutout mode, insets pushed to the page in dp, keyboard handled by padding because `adjustResize` stops resizing in edge-to-edge); Battery Saver and animation-scale pushes; `WebView.onPause/onResume` with the activity.
- `AndroidManifest.xml`: portrait lock removed (rotation follows the phone's setting), `resizeableActivity`, more `configChanges`, `enableOnBackInvokedCallback`, HOME in `<queries>`.
- `build.gradle.kts`: `versionName = "1.51"`.

## Not changed / to check on a device
- Android 8-10 keep black system bars (no edge-to-edge).
- Landscape and tablets show the phone-style column centred; there is no two-pane layout.
- Real Android widgets (`YogaWidgets`) are placed from page coordinates; check them after rotating.
- `WebView.textZoom` stays 100, so the phone's font size does not change the page; use Settings > Text size.
- The Kotlin changes were written without a compiler here; build once (`./gradlew assembleDebug`) and read any error list.
