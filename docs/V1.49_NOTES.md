# v1.49: Motion lab

Everything is in `app/src/main/assets/index.html` (plus `Android.haptic` in `YogaBridge.kt` from v1.48).
Each effect has its own switch in **Settings > Themes & Look > Arcs**, and the Whisper preset turns them all off.
All of them need Motion effects = Full, and switch themselves off in Performance mode and with reduced-motion.
The opening-animation effects (fan from the thumb corner, dial spin, colour wash) also need Opening animation set to anything but Off.
A fresh install starts in Minimal mode (Opening animation Off, Smooth performance), so switch those first to see them.

| Setting | Effect |
|---|---|
| `dsq` | Icons stretch along the arc when you fling |
| `dhp` | Haptic detents, speed-aware (light tick when fast, full click when slow, heavy click at the end of the list) |
| `dmass` | Often-opened apps are heavy (stretch less, keep up); rarely-opened apps trail behind |
| `dpred` | Often-opened apps fan out first when the drawer opens |
| `dbeat` | Apps with notifications pulse like a heartbeat; more unread = faster |
| `dorg` | The fan swings up from the bottom (thumb corner) when opening |
| `drot` | Switching category slides the arc in like a dial, in the direction of the chip order |
| `dflood` | The tapped icon's own dominant colour washes outward as the app opens |
| `dlite` | A light glint slides across the icons as the wheel turns, and shifts with phone tilt |
| `dpar` | Tilt parallax inside the drawer (big letter far, icons near); needs "Tilt the phone for depth" |
| `dgrav` | Apps that stop matching drop away as you type |
| `dliq` | The focus lens stretches with speed, then wobbles to rest |

Not done: finger-tracked open (needs the home-screen swipe code) and the SVG goo filter (too heavy for a WebView), so "Jelly focus lens" is a spring-driven stretch instead.

## Fix included
Earlier v1.48 never measured wheel speed (the timer was only set inside the branch that needed it), so stretch never showed and haptics always played the full click. Fixed here.

Tested in headless Chromium: no script errors; stretch, lens jelly, glint, dial spin, colour wash, drop-away and fan-from-bottom all fire and clean up. Not tested on a real phone.
