# v1.61: Glass capsule clock is now a real 3D render

The home clock capsule (Settings > Clock > Home clock style > Glass capsule) was replaced with the new glass capsule design. Everything around it works as before.

- Hour, minute and second drums are true cylinders drawn with WebGL 2 (curved numbers, lighting from above, motion blur while rolling). The glass is a real tube that reflects a studio light panel, with thick rim glass, end pins and dimples.
- The old day cylinder is now a printed label at the left, in the old "Capsula" spot: MON in caps by default.
- New Clock settings: Show day / date label, Label shows (Day MON | Day name | Date), Label font (Condensed caps, Heavy caps, Serif caps, Mono caps, Script, Casual), Label size, Glass reflection (was Ambient light), Show seconds. In 12-hour mode a small AM/PM sits under the label.
- Same behaviour as v1.59: tap = apps, hold = Settings > Clock, drag/resize with Layout > Move clock & date, follows 24-hour time. No roll animation in reduced motion, Performance and Stealth modes; nothing is drawn while the apps drawer covers the clock or the page is hidden. The image is only redrawn when something changes, so idle battery use stays low.
- Reflections shift slightly as the finger or pointer moves (off in reduced motion / Performance / Stealth / Lite).
- Fonts: system fonts only, no internet needed (Oswald / Roboto Condensed / Android condensed, otherwise the default font squeezed).
- Needs WebGL 2 (any current Android System WebView). If it is missing, the launcher uses the dial.
- Not changed: the lock screen clock, the dial, all Kotlin code.
- Changed: `app/src/web/index.src.html` and generated `assets/index.html`; `APP_VER` / `versionName` 1.61.
- Checked in headless Chromium at 390x844: capsule draws, 12h and 24h, label options, seconds off, switch to Dial and back, no page errors. Not yet checked on a real phone.
