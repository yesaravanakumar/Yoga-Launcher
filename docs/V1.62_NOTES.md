# v1.62: Swipe between home pages, lighter page changes

- **Swipe sideways on the home screen to change home page** (only when you have 2 or more pages). It works from empty space and from icons. Swipe left = next page, swipe right = previous page.
- At the edges nothing changes: on the **first** page a swipe right still opens apps, on the **last** page a swipe left still runs your Swipe left action (Settings > Gestures). The page dots still work as before.
- **Less work per page change:** the dots are no longer torn down and rebuilt each time (only the highlighted dot moves), the slide is shorter and goes in the swipe direction, and it is skipped in Performance, Stealth and reduced motion. Only the icons of the new page are drawn. The clock, date and capsule are not touched, so nothing flashes or restarts.
- **Lighter capsule:** the capsule's label picture is only rebuilt when a clock setting actually changed (before, any settings refresh rebuilt it), and the picture is capped at 2x resolution instead of 3x.
- The page you are on is still remembered, also after the app is closed.
- Changed: `app/src/web/index.src.html` (page dots, page change, new `v162-home-swipe` script, capsule apply) and generated `assets/index.html`; `APP_VER` / `versionName` 1.62. No Kotlin change.
- Checked in headless Chromium (390x844, touch): swipe left/right changes page, from empty space and from an icon, edge swipes still open apps, dots work, page kept after reload, no page errors. Not yet checked on a real phone.
