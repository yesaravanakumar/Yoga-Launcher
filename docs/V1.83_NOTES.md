# v1.83: Arc line-follow fix

Symptom: while scrolling the arc drawer the icons trailed behind the flow line and swam off it (up to ~50 px in a headless test),
then snapped back at rest.

Cause: the arc icons are `<button class="awi">`, and `html.cyber button{transition:transform .35s ...,opacity .3s ...}` applied to them.
The engine writes the exact curve position every frame, so the .35 s ease made every icon lag the line.

Changes
- `html.cyber #aw .awi,#aw#aw .awi{transition:none!important}`: position and opacity are applied instantly.
- `#aw.busy .awi:active .ic{transform:none!important}`: the pressed icon no longer shrinks while the wave moves.
- Magnetic selection (`fx_magnet`) is skipped while the wave is dragged or flung.

Check: drag and fling in Arc, Wave, Orbit and Fan at 390x844 with FX on and off: every icon within 0.1 px of `slot()`.
Test script: `tools/smoke/arc-line-follow-test.py` (needs Playwright; run from the repo root).
