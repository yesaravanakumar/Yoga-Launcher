# v1.84: Dial is the default home clock

- `hck` default changed from `capsule` to `dial` (Glass capsule clock module, `const D={hck:'dial',...}`).
- The glass capsule clock is still available: Settings > Home clock > Style.
- Only fresh installs and Reset use the new default. A phone that already saved `hck:'capsule'` keeps it until the style is changed
  (Settings > Home clock > Style > Dial, or the Reset button in that section).
