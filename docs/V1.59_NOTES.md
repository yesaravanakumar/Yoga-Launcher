# v1.59: Glass capsule home clock (new option)

- **Settings > Clock > Home clock style: Dial | Glass capsule.** Glass capsule is the default (Dial is one tap away). The capsule is the glass-capsule-clock.html design (rolling day / hour / minute / second drums behind curved glass), built into the home page.
- Capsule options: Show seconds, Show day cylinder, Ambient light. It also follows 24-hour time, Show date, and Layout > Move clock & date (drag and resize).
- Tap the capsule = apps (same as the hour on the dial). Hold it = Settings > Clock. Swipes over it still change home page.
- Dial-only options (readout look, hour style, seconds arc...) are hidden while the capsule is on. The dial, hour and time pill are hidden and their per-frame drawing is switched off, so the capsule does not add battery use.
- Battery / modes: no roll animation or glass sway in reduced motion, Performance and Stealth modes; the heavy glass layers are dropped in Lite mode; nothing updates while the apps drawer covers the clock or the page is hidden.
- Needs a WebView with CSS container units (Chrome 105+). On an older WebView the option is not offered and the dial is used.
- Fonts: uses Oswald / Roboto Condensed / system condensed if present, otherwise squeezes the default font (no internet font needed).
- Changed: `app/src/web/index.src.html` and generated `assets/index.html`; `APP_VER` and `versionName` 1.59. No Kotlin change.
- Checked in headless Chromium (390x844): switch both ways, tap opens apps, 12h AM/PM, seconds and day toggles, saved across reload, no page errors. jsdom smoke tests not run.
- Fix: a stray literal "
" shown in Settings above Look & Theme (from the Settings HTML) is gone.
