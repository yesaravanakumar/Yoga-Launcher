# v1.45 (app groups)

- Groups: Games, Media, Comms, Social, Shop & Pay, Travel, Health, Read & Learn, Work, Tools, Other
- Each app is placed by, in order: your own choice > Android's game flag > name/package rules (whole words only, so "Solar" no longer matches "ola") > the category the app declares to Android > system apps (Tools) > Other
- New: App options > Change group moves one app to any group (or back to Automatic). Saved in mdc-catov
- Android (YogaBridge.kt): pushApps now sends the app's declared category as "k"
- Not yet tested on a phone; check the GitHub Actions build
